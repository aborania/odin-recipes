# odin-recipes
My First Webpage

This project is my first webpage, created as part of my learning journey through The Odin Project.

The purpose of this project is to practise the fundamentals of web development using HTML. It covers basic HTML document structure, headings, paragraphs, links, images, and lists.

Through this project, I aim to build a strong foundation in HTML and gain practical experience creating and structuring web pages.

Technologies Used

HTML5

What I Learned

Creating a basic HTML document.

Using HTML elements and tags.

Structuring content with headings and paragraphs.

Adding links and images.

Organising information using lists.
